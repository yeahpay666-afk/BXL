🔑角色管理模块

角色管理是中台权限体系的核心入口。角色是权限的载体，岗位绑定角色，用户通过岗位继承角色权限，形成"岗位 → 角色 → 权限"的单向链路。

1角色列表页（role-list.html）

页面结构

  • 顶部统计卡片：5个卡片展示角色总数、启用中、禁用、超级管理员、关联用户总数
  • 筛选栏：支持按角色名称/编码搜索 + 状态下拉筛选（全部/启用/禁用）
  • 角色列表表格：以卡片形式包裹，含分页组件

表格字段

列名宽度说明
角色名称自适应显示角色图标+名称，如 👑 超级管理员
角色编码170px系统编码，如 ROLE_SUPER_ADMIN
描述自适应角色功能简述
关联岗位数90px蓝色链接，点击跳转岗位管理页并按角色筛选
关联用户数90px蓝色链接，点击跳转用户管理页并按角色筛选
状态90px绿色"启用" / 灰色"禁用"标签
创建时间120px格式 YYYY-MM-DD
操作210px配置权限 / 编辑 / 禁用（或启用）

操作功能

操作触发方式行为
配置权限 点击链接 跳转 permission-config.html?role=角色名称，进入权限配置页
编辑 点击链接 打开编辑弹窗，可修改角色名称、描述、可访问据点（组织架构树选择）、排序、状态
禁用/启用 点击链接 切换角色状态，禁用后角色权限不生效
新增角色 点击页面右上角按钮 打开新增弹窗，填写角色名称、编码、描述、可访问据点、排序、状态

跳转逻辑（URL参数传递）

  • 关联用户数：user-role.html?role=超级管理员
  • 关联岗位数：position-manage.html?role=超级管理员
  • 配置权限：permission-config.html?role=超级管理员
  • 目标页面接收 role 参数后，自动筛选该角色关联的数据

2用户管理页（user-role.html）

定位

角色管理的二级页面。从角色列表点击"关联用户数"进入，展示该角色关联的用户列表。侧边栏"角色管理"保持高亮。

页面结构

  • 页面头部：面包屑导航 + 标题 + 刷新按钮 + 导出列表按钮
  • 返回按钮：点击返回角色管理列表页
  • 筛选栏：支持用户姓名、工号搜索
  • 用户列表表格

表格字段

列名说明
序号自增序号
用户姓名用户真实姓名
工号员工工号
部门所属部门
岗位关联岗位名称
状态启用/禁用标签
操作查看详情（弹窗显示完整用户信息，含关联角色）

设计约束

  • 不展示"关联角色"列 — 因从角色列表跳转进入，角色已明确，展示该列属冗余信息
  • 用户数据为只读引用，不可新增/编辑/删除，维护入口仅在中台
  • 支持导出列表（CSV格式，含序号、用户姓名、工号、部门、岗位、状态）

3岗位管理页（position-manage.html）

定位

角色管理的二级页面。从角色列表点击"关联岗位数"进入，展示该角色绑定的岗位列表。侧边栏"角色管理"保持高亮。

页面结构

  • 页面头部：面包屑导航 + 标题 + 导出列表按钮 + 刷新按钮
  • 返回按钮：点击返回角色管理列表页
  • 筛选栏：岗位名称、岗位代码输入 + 状态下拉
  • 岗位列表表格

表格字段

列名说明
序号自增序号
岗位名称岗位全称
岗位代码系统编码
岗位分类如：管理类、技术类、业务类
状态启用/禁用标签
更新时间最后修改时间
备注信息补充说明
操作查看详情（弹窗显示岗位关联的角色信息）

设计约束

  • 岗位数据为只读引用，不可新增/编辑/删除，维护入口仅在中台
  • 支持导出列表（CSV格式，含序号、岗位名称、岗位代码、岗位分类、状态、更新时间、备注信息）
  • 岗位管理使用三级树形选择器同步组织架构数据

4权限配置页（permission-config.html）

定位

角色管理的二级页面。从角色列表点击"配置权限"进入，为指定角色配置各维度权限。角色信息只读展示，不显示"选择角色"下拉。

权限模型（6维度）

权限维度关联对象管控内容
菜单权限菜单控制角色可访问的菜单页面
按钮权限按钮控制页面内操作按钮的可见性
字段权限字段3种：不可见、不可更改、部门可见（数据脱敏）
部门数据权限菜单9级（0-8），按部门间管控查改删权限
个人数据权限菜单5级（0-4），控制他人资料的查改删权限
日期管控菜单单据日期/扣账日期是否可修改

页面结构

  • 顶部显示当前角色名称（只读）
  • 业务系统下拉：角色"可访问的系统"为指定系统时禁用切换，为"全部系统"时允许切换
  • Tab页切换：菜单权限 / 按钮权限 / 字段权限 / 部门数据权限 / 个人数据权限 / 日期管控
  • 底部统计：不可视字段数、部分加密字段数、不可修改字段数

1系统列表页（system-manage.html）

页面结构

  • 页面头部：面包屑导航 + 标题 + 刷新按钮 + 新增系统按钮
  • 筛选栏：系统名称输入 + 状态下拉 + 查询/重置按钮
  • 系统列表表格：含分页组件

表格字段

列名宽度说明
序号50px自增序号
系统名称自适应系统显示名称，加粗
系统编码自适应如 SYS_T100，等宽字体显示
系统描述自适应系统功能简述
状态80px正常/停用标签
更新时间140px最后修改时间
操作260px编辑 / 菜单配置 / 其他资源配置 / 停用（或启用）

操作功能

操作行为
编辑 打开编辑弹窗，系统编码保存后锁定不可修改
菜单配置 进入菜单配置页面，管理该系统的菜单层级结构
其他资源配置 打开弹窗，配置部门数据权限、个人数据权限、日期管控、单身明细
停用/启用 切换系统状态
新增系统 打开弹窗，填写系统名称、编码（保存后锁定）、描述、排序、状态

2菜单配置功能

布局结构

  • 左侧菜单树：树状导航，支持5级层级展开/折叠
  • 右侧扁平化表格：以表格形式展示所有菜单，带 L1/L2/L3/L4/L5 标签和层级缩进
  • 顶部操作："新增菜单"按钮

新增菜单弹窗

字段必填说明
菜单名称必填菜单显示名称
权限码选填菜单权限标识，如 01、axmt500
上级菜单必填下拉选择，首项为"（根）"新增一级菜单；其余选项展示现有菜单带层级缩进和 L1/L2/L3 标签
排序选填默认值 10
状态选填启用/停用，默认启用

层级约束

  • 菜单最多支持 5级 层级
  • 当上级菜单为 L5 时，该行的"添加子菜单"按钮禁用，并提示"最多支持5级菜单"
  • 选择父级后，新菜单自动设为其子级（level + 1）

3其他资源配置功能

布局结构

  • 弹窗形式，标题显示"其他资源配置 · 系统名称"
  • 4个Tab页切换：部门数据权限 / 个人数据权限 / 日期管控 / 单身明细
  • 每个Tab包含：表格列表 + "+ 新增"按钮
  • 表格操作列：查看 / 编辑 / 删除

4个Tab的表格列与新增表单

Tab表格列新增表单字段
部门数据权限 序号 · 代码 · 权限名称 · 管控范围 · 查询 · 修改 · 删除 · 操作 基本信息（权限代码*、权限名称*）→ 管控范围（下拉：不同部门间/仅相关部门群组间/所有部门）→ 操作权限（3个开关：允许查询/允许修改/允许删除）→ 说明
个人数据权限 序号 · 代码 · 权限名称 · 查询他人 · 修改他人 · 删除他人 · 说明 · 操作 基本信息（权限代码*、权限名称*）→ 他人操作权限（3个开关：查询他人/修改他人/删除他人）→ 说明
日期管控 序号 · 代码 · 权限名称 · 单据日期可改 · 扣账日期可改 · 说明 · 操作 基本信息（权限代码*、权限名称*）→ 日期控管（2个开关：单据日期可改/扣账日期可改）→ 说明
单身明细 序号 · 代码 · 权限名称 · 新增明细 · 删除明细 · 修改明细 · 说明 · 操作 基本信息（权限代码*、权限名称*）→ 明细操作权限（3个开关：新增明细/删除明细/修改明细）→ 说明

新增表单设计特点

  • 分区式布局：基本信息 → Tab专属权限区 → 说明，每区带图标标题
  • 开关控件：所有 Y/N 权限使用蓝色动画开关（Toggle Switch），替代传统下拉/复选框
  • 每个开关包含图标 + 标签 + 描述说明，清晰展示权限含义
  • 查看模式下开关为禁用状态（灰色不可点击）

联动机制

  • 单向权限链路：岗位管理选择角色 → 用户通过岗位继承角色权限
  • 角色管理（中台权限）：定义角色可访问哪些系统、菜单、按钮、字段
  • 应用系统管理（业务系统权限）：为每个系统定义更细粒度的数据权限维度
  • 数据一致性：业务系统中的用户、角色、岗位均为只读引用，维护入口仅在中台，确保单一数据源
  • 权限配置页：从角色管理进入时，业务系统下拉根据角色"可访问的系统"动态控制——指定系统时禁用切换，全部系统时允许切换

设计约束汇总

约束项说明
用户/角色/岗位只读业务系统侧不可编辑，维护入口仅在中台
权限配置不单独展示仅从角色管理列表页跳转进入
角色信息只读展示权限配置页不显示"选择角色"下拉
菜单最多5级L5级菜单禁用"添加子菜单"
系统编码锁定新增系统保存后编码不可修改
组织架构三级集团 → 部门 → 子部门，支持多选和父子联动
字段权限三类不可见、不可更改、部门可见（对应数据脱敏）
